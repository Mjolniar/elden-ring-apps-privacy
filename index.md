# Privacy Policy

**Applies to:** Elden Ring Randomizer Index and Build Planner · Elden Ring Index and Build Planner  
**Last updated:** 2026-05-10

---

## Summary

These apps collect no personal data. They run entirely on your device. Nothing is sent to any server.

---

## What the apps store locally

Both apps save a small amount of data to your device using your browser's localStorage or the Electron app's local file system. This data never leaves your computer.

| Data | Where stored | Purpose |
|------|-------------|---------|
| Starred (favorited) items | localStorage | Remember items you starred across sessions |
| Acquired item state | localStorage | Remember which items you marked as collected |
| Spoiler mode settings | localStorage | Remember your Settings tab preferences |
| Custom builds | localStorage | Persist build checklists you created |
| Favorited build presets | localStorage | Remember which presets you starred |
| Last loaded spoiler log *(Randomizer edition only)* | Local file next to the executable | Restore your session on next launch without re-loading the file |

All of this data is stored only on your device. It is not transmitted, synced, or backed up anywhere.

---

## What the apps do not do

- Do not make any network requests
- Do not contact any server or backend
- Do not collect analytics or usage data
- Do not use cookies
- Do not track identifiers of any kind
- Do not read, modify, or interact with Elden Ring game files or the running game process
- Do not install background services or auto-updaters

---

## Outbound links

The only outbound navigation these apps initiate is when you explicitly click a wiki link on an item name. These links open pages on [eldenring.wiki.fextralife.com](https://eldenring.wiki.fextralife.com) in your default browser. That site's own privacy policy applies once you navigate there.

---

## Spoiler log files *(Randomizer edition only)*

The Randomizer edition asks you to load a `.txt` spoiler log file from your computer. This file is read locally and never transmitted. A cached copy is stored in a `cached-spoiler-logs\` folder next to the app executable so your session can be restored on next launch. You can clear this cache at any time using the "Load new log" button in the app.

---

## Children's privacy

These apps do not knowingly collect any information from anyone. There is no data collection of any kind.
